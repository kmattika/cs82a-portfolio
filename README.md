### B. Final Project

**Washington State Registration-to-Voter Gaps**

This project examines differences between voter-registration estimates and accepted-ballot estimates across demographic groups in Washington State for the 2020, 2022, and 2024 general elections. It includes data cleaning and validation, comparisons of count and percentage gaps, visualizations, and discussion of implications for 2026.
